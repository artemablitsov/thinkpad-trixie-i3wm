# Third-party material

Cyberdeck's own code and configs are under the [MIT licence](LICENSE). These files in the repository come from, or are based on, other projects and keep their own terms:

| Path | Origin | Licence |
|---|---|---|
| `system/usr/share/plymouth/themes/cubes-nord/` | the *cubes* theme from [adi1090x/plymouth-themes](https://github.com/adi1090x/plymouth-themes), frames recoloured to Nord | GPL-3.0 (see the `LICENSE` file in that directory) |
| `lib/patches/tuigreet-title.patch` | a patch to [apognu/tuigreet](https://github.com/apognu/tuigreet) | GPL-3.0, like tuigreet |
| `config/zsh/p10k.zsh` | generated by the [Powerlevel10k](https://github.com/romkatv/powerlevel10k) wizard; settings and layout after [sasha-sup/dotfiles](https://github.com/sasha-sup/dotfiles), colours changed to Nord | Powerlevel10k: MIT |
| `config/kitty/kitty.conf`, `config/picom/picom.conf`, `bin/cyberdeck-lock` (i3lock-color options) | settings after [sasha-sup/dotfiles](https://github.com/sasha-sup/dotfiles), recoloured to Nord | credited; the upstream repository states no licence |
| `wallpapers/ai-ecosystem.png` | the "AI Ecosystem" chalkboard picture | not covered by the MIT licence; rights belong to its author |

Everything else the installer uses — the Nordic theme, Nerd Fonts, Oh My Zsh, Neovim plugins, the programs from GitHub releases — is downloaded at install time from its upstream at a pinned version (`lib/versions.sh`, `config/nvim/lazy-lock.json`) and is not part of this repository.

The colour values are the [Nord palette](https://www.nordtheme.com) (MIT).
